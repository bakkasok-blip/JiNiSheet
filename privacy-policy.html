JiNi Sheet 개인정보처리방침

시행일: 2026년 8월 6일

JiNi Sheet는 사용자가 선택한 스프레드시트 파일을 브라우저 내부에서 열고, 계산·편집·저장할 수 있도록 제공되는 오프라인 확장프로그램입니다.

처리하는 정보

확장프로그램은 사용자가 직접 연 파일의 셀 내용, 수식, 서식 및 매크로 코드를 기능 제공을 위해 처리합니다. 작업 중인 통합문서는 자동 복구를 위해 사용자의 브라우저 로컬 저장소에 저장될 수 있습니다.

이용 목적

정보는 스프레드시트 표시, 수식 계산, 편집, 자동 복구, 파일 저장 및 사용자가 요청한 내보내기 기능에만 사용됩니다.

외부 전송 및 공유

JiNi Sheet는 파일 내용, 셀 데이터, 수식, 매크로 또는 사용 기록을 개발자나 외부 서버로 전송하지 않습니다. 데이터를 판매하거나 광고, 신용평가 또는 제3자 마케팅 목적으로 사용하지 않습니다.

제한적 사용

JiNi Sheet의 사용자 데이터 사용은 공개된 단일 목적인 로컬 스프레드시트 열기, 계산, 편집, 자동 복구 및 파일 저장 기능 제공으로 제한됩니다. 사용자 데이터를 판매하거나 맞춤형 광고, 재타기팅, 관심 기반 광고, 신용평가 또는 단일 목적과 관련 없는 용도로 사용하지 않습니다. 사용자의 명시적 동의가 있는 지원 요청, 보안상 필요한 경우 또는 법률상 의무가 있는 경우를 제외하고 사람이 사용자 데이터를 읽도록 허용하지 않습니다. JiNi Sheet는 Chrome 웹스토어 사용자 데이터 정책과 Limited Use 요건을 준수합니다.

보관과 삭제

작업 데이터는 사용자의 기기 안에 보관되며 다른 통합문서로 덮어쓰거나 확장프로그램을 제거하면 삭제될 수 있습니다. 사용자가 다운로드한 파일은 사용자가 선택한 위치와 브라우저 다운로드 정책에 따라 보관됩니다.

권한

unlimitedStorage 권한은 큰 통합문서와 자동 복구 데이터를 로컬에 안정적으로 보관하고 저장소 할당량 또는 제거로 인한 작업 손실을 줄이기 위해 사용됩니다.
